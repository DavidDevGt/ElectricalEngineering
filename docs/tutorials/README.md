# tutorials/ — Cuadrante Tutorial

Este cuadrante responde **"¿puedes enseñarme a...?"** — experiencias guiadas paso a paso para
alguien que aún no sabe usar el simulador, con resultados visibles temprano y a menudo, minimizando
la explicación teórica (esa vive en [`../explanation/`](../explanation/README.md); un tutorial no
debe desviarse a explicar teoría — ver
[investigación 13 §1.2](../../investigaciones/13-documentacion-framework-diataxis.md)).

## Tutoriales disponibles

|---|---|---|
| 1 | [Tu primera inspección del transformador](01-tu-primera-inspeccion-del-transformador.md) | Levantar el simulador y descubrir, moviendo un slider, por qué existe un punto de carga de máxima eficiencia |
| 2 | [Tu primera maniobra segura](02-tu-primera-maniobra-segura.md) | Energizar una bahía completa siguiendo la secuencia correcta interruptor/seccionador, y ver el enclavamiento bloquear la secuencia incorrecta con su razón |

## Próximos tutoriales (a escribir cuando exista el modo correspondiente)

- Tu primera falla simulada: inyectar un cortocircuito y observar la secuencia de protección (modo falla, fuera de alcance del MVP actual).

Cada tutorial nuevo debe seguir la disciplina de escritura de este cuadrante: primera persona del
plural para el narrador ("vamos a..."), segunda persona para quien lee, resultado visible en cada
paso, y ninguna digresión teórica — esa va enlazada, no incrustada.
