# Niveles de tensión (IEC 60038)

| Categoría | Rango (AC) |
|---|---|
| Baja tensión (BT / LV) | ≤ 1 kV |
| Media tensión (MT / MV) | 1 kV – 35 kV |
| Alta tensión (AT / HV) | 35 kV – 230 kV |
| Extra alta tensión (EAT / EHV) | > 230 kV (tablas hasta 1200 kV) |
| Ultra alta tensión (UHV) | > 800 kV (uso informal del término) |

Valores normalizados preferentes de uso común (varían por región/operador): 66, 132, 220, 230, 400,
500, 765 kV.

Ver también: [`coordinacion-aislamiento-bil-bsl.md`](coordinacion-aislamiento-bil-bsl.md) para el
nivel de aislamiento asociado a cada rango de tensión.
